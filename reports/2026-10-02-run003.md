## Decided, and why
- **D-002** Who computes the exact positions for along, between and distributed over? No phase-2 task places objects by relations; P2-T04 covers distributions as geometry, not as script relations. -> **Add a task P2-T05 'Place by relations: every relation computed exactly', after P2-T04, extending geometry/placement.py to along, between, distributed over and corner features, with hand-computed tests per relation.** (by default)
  - why: P1-T04 decided WHICH relation fixes each direction of every object (lang/anchoring.py) and computed the numbers for at, centred on, next to, offset from and aligned with. The rest needs real geometry (edges, long axes, spans), which is phase 2's job; without a task naming it, nothing in the plan would ever compute them, and the solver door would stay half built.
  - taken as the default because it was unanswered; reversible, say so and it is undone
- **D-003** How does the user say 'n mm in from the top edge of the plate'? Removing the sides inside/outside (they name no edge) left no way to measure from one edge of an object towards its interior. -> **In phase 2 (with notable points, P2-T04), let a target name an edge or a corner of an object -- 'plate1 top', 'plate1 top_left' -- so 'offset from plate1 top by 15 mm on side below' is exact. Until then, such holes are placed relative to another feature (as the SCRIPT.md bracket does).** (by default)
  - why: Measuring from an edge is how a mechanical drawing is dimensioned, so it cannot stay missing. Edges and corners are exactly the notable points P2-T04 exposes, so the grammar word and the geometry arrive together; adding the word now, before anything can compute it, would let the script say what the solver cannot do.
  - taken as the default because it was unanswered; reversible, say so and it is undone

## Wanted from Marco
- **D-004** How are 'N copies distributed over X' spaced? Example: 4 holes of 6.5 mm over a 200 mm plate.
  - proposal: Centres equally spaced with equal gaps at the ends too: N copies, N+1 equal centre-to-centre spaces (40, 80, 120, 160 mm for the example). Copies that would overlap are refused.
  - reversible: if you say nothing, this is what happens, and it can be undone
- **D-005** What does 'between A and B' mean when A and B are rectangles, e.g. 'wall_east: between living and kitchen'?
  - proposal: When both targets are rectangles that touch along an edge, the object lies on that shared edge (a wall straddles it, centred). Two rectangles that share no edge are refused with the reason. Between round things, symbols and points it stays reference point to reference point (centres), as the catalogue says.
  - reversible: if you say nothing, this is what happens, and it can be undone
- **D-006** A corner can carry one feature. The SCRIPT.md bracket puts a fillet on every corner (corner all) and a chamfer on top_left too, and the solver accepts both. What should happen?
  - proposal: Refuse a second corner feature on a corner already taken, naming both; change the bracket example so the chamfer is on its own corner (a fillet per remaining corner instead of corner all).
  - reversible: if you say nothing, this is what happens, and it can be undone
